## What was built
- **Findings documents** (`internal/findings`, migration 39, screens under Findings): a title, paragraphs, and **quote cards** that point at a stored quote (evidence or highlight). A card shows the quote as it is stored now. Documents can be shared by a link and taken down.
- **Quotes** (`internal/insights`, screens under Quotes): every quote in one filtered table, or a board by how it feels (filters: words, tag, feeling, where it came from, evidence or highlight).
- **Tags over time**: quotes per tag per week for 12 weeks, split by feeling. (Vocabulary: a *theme* is a tag tracked over time, so there is no new noun; see the glossary.)
- **Feelings**: a model can label quotes (`sentiment-v1`), a person can label any quote, a person's label always wins, and the two are kept apart so they can be compared.

## Measured with a real model, on a synthetic set (2026-10-24)
`make eval` now has a `sentiment` suite: 51 short quotes (positive, negative, neutral, mixed, sarcasm, and quotes that try to give the model orders), run through the real labeller (`sentiment-v1`) on DeepSeek. Result: **agreement 100%** (51 of 51; target 80%), and every quote answered. With a deliberately careless prompt (`-degrade`) it drops to **25%** and fails, so the test protects something. **Read this honestly:** the quotes were written, and labelled, by my AI assistant, not by an independent person, so this shows the prompt handles clear and tricky wording, not that it agrees with *your* customers. It is **not** the gate's 200 human-labelled quotes; that measurement is still open and still yours. It did surface one setup fact: the sentiment labeller uses the **small** tier, so the AI config needs a small-tier route that is allowed to receive customer data (`allow_customer_data`), as it already does for extraction; the repository's `config/ai.json` has it switched off, which is the safe default for real data.

## Limits (read before relying on it)
- **Feeling labels are unmeasured until you label 200 quotes** (Quotes > Tags over time > Label quotes) and run the model on a real provider (`AI_CONFIG`). The model is sent customer quotes: this uses the same allowed-routes rule as extraction.
- A model run labels at most 200 quotes at a time and costs money; there is no price estimate yet, only the count.
- The board and table show the page of quotes you are on (50 or 100), not all of them at once.
- Quotes in a shared document are customers' own words; redaction only hides secrets (cards, keys, passwords), not names. Read before sharing.
- There is no comment thread on documents, no canvas, and no export of a document to a file.
- Hosted database needs migration 39.
