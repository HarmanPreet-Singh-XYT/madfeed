## Bugs found while closing the gate
- Unsubscribe links exposed the recipient's address in URLs and logs (fixed; see above).
- The audit service was wired before the services it depends on, crashing the first request that used it. Unit tests passed because they wire in a different order. The server now checks its own wiring at startup and refuses to run incomplete (`Server.Validate`, tested).
- Closing the import request type exposed that `skipInvalidRows` was declared next to it through `allOf`; the import route now has its own closed type.
- A flaky assertion of mine (about one in eight) looked for `@` in random token bytes; now checks for the address itself.
- My drill scripts failed three times for their own reasons (wrong log format, missing AI configuration, parsing); each is fixed and the scripts now run clean.
- Earlier in the phase: sweeps that proved little because requests were refused for their shape; a timing test that failed only under the race detector; two commits made while a check was failing (commits are now gated on green).
